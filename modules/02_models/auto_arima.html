Automatic ARIMA Modeling via Hyndman-Khandakar Stepwise Algorithm

auto_arima

def auto_arima(
    target_col:str, # Name of the target column in the input DataFrame.
    seasonal_length:Optional[int]=None, # Seasonal period length (e.g. 7 for daily with weekly pattern, 12 for monthly with annual pattern).
    # Default is None (non-seasonal).
    d:Optional[int]=None, # Integration/differencing order. If None (default), determined automatically via repeated
    # stationarity testing (KPSS).
    D:Optional[int]=None, # Seasonal differencing order (typically 0 or 1). If None (default), determined automatically
    # upfront using a seasonal unit root / strength test ('seasonal_test') before model search.
    max_p:int=5, # Maximum non-seasonal AR order.
    max_q:int=5, # Maximum non-seasonal MA order.
    max_P:int=2, # Maximum seasonal AR order.
    max_Q:int=2, # Maximum seasonal MA order.
    max_d:int=2, # Maximum non-seasonal differencing order tested during stationarity check.
    max_D:int=1, # Maximum seasonal differencing order tested when D is None.
    start_p:int=2, # Initial p order for Hyndman-Khandakar stepwise search.
    start_q:int=2, # Initial q order for Hyndman-Khandakar stepwise search.
    start_P:int=1, # Initial P order for seasonal Hyndman-Khandakar stepwise search.
    start_Q:int=1, # Initial Q order for seasonal Hyndman-Khandakar stepwise search.
    max_order:Optional[int]=None, # Maximum sum of orders (p + q + P + Q). If None, no cumulative constraint is applied.
    stepwise:bool=True, # Whether to use the Hyndman-Khandakar stepwise search algorithm. If False, an exhaustive
    # grid search over all combinations within max orders is performed.
    criterion:str='aicc', # Information criterion to minimize ('aicc', 'aic', or 'bic').
    stationarity_test:str='kpss', # Statistical test used to determine non-seasonal differencing order d ('kpss' or 'adf').
    seasonal_test:str='seas', # Method used to determine seasonal differencing order D when D is None:
    # - 'seas' (default): Wang-Smith-Hyndman seasonal strength test (F_s > 0.64).
    # - 'ocsb': Osborn-Chui-Smith-Birchenhall seasonal unit root test (requires pmdarima).
    alpha:float=0.05, # Significance level for the stationarity / seasonal differencing tests.
    with_intercept:Optional[bool]=None, # Whether to include a constant / drift term. If None (default), constant is tested according
    # to Hyndman-Khandakar rules (included unless d + D >= 2, and evaluated in variations).
    lag_transform:Optional[list]=None, # List of lag transform functions for exogenous feature generation.
    trend:Optional[str]=None, # Deterministic trend removal strategy ('linear' or 'ets').
    pol_degree:int=1, # Degree of polynomial trend when trend='linear'.
    ets_params:Optional[Dict[str, Any]]=None, # Parameters for ETS trend model when trend='ets'.
    change_points:Optional[List[int]]=None, # Change point indices for piecewise linear trend.
    box_cox:Union[bool, float, int]=False, # Whether to apply Box-Cox transformation (or fixed lambda value).
    box_cox_biasadj:bool=False, # Whether to apply bias adjustment when back-transforming Box-Cox forecasts.
    cat_variables:Optional[List[str]]=None, # List of categorical covariate column names.
    categorical_encoder:Optional[Any]=None, # Categorical encoder instance (e.g. OneHotEncoder).
    target_encode:bool=False, # Whether target encoding is applied.
    maxiter:int=200, # Maximum L-BFGS-B iterations per candidate ARIMA model.
    tol:float=1e-07, # Convergence tolerance for optimizer.
    trace:bool=False, # Whether to print candidate models and their criterion scores during search.
    **kwargs
)->None:

Automatic ARIMA / SARIMA model selection implementing the Hyndman-Khandakar (2008) stepwise search algorithm and exhaustive grid search under the unified peshbeen pipeline.

The algorithm determines integration order d via stationarity tests (KPSS/ADF), and seasonal integration order D upfront via seasonal strength testing (F_s > 0.64) or OCSB tests. With differencing fixed for valid likelihood comparisons, it evaluates initial candidate models and performs a stepwise traversal of neighboring (p, q, P, Q) variations to minimize the sample-size corrected AICc (or AIC, BIC). Exogenous regressors, Box-Cox transformations, lag transforms, and trend handling are fully supported and evaluated within the native arima engine.

def check_seasonal_D(
    y:np.ndarray, # 1D target time series array.
    seasonal_length:int, # Seasonal period length (e.g. 7 for daily, 12 for monthly).
    max_D:int=1, # Maximum seasonal differencing order (typically 1).
    test:str='seas', # Seasonal test to apply:
    # - 'seas' (default): Wang-Smith-Hyndman seasonal strength test F_s > 0.64.
    # - 'ocsb': Osborn-Chui-Smith-Birchenhall seasonal unit root test.
    alpha:float=0.05, # Significance level.
)->Tuple[int, List[Dict[str, Any]]]: # The determined seasonal differencing order (0 <= D <= max_D).

Determine the seasonal integration order D using seasonal unit root / strength tests (Wang, Smith & Hyndman 2006 / Osborn-Chui-Smith-Birchenhall 1988).

def check_stationarity_d(

    max_d:int=2, # Maximum differencing order to consider.
    alpha:float=0.05, # Significance level for the stationarity hypothesis test.
    test:str='kpss', # Stationarity test to apply: 'kpss' (Kwiatkowski-Phillips-Schmidt-Shin) or 'adf' (Augmented Dickey-Fuller).
)->Tuple[int, List[Dict[str, Any]]]: # The determined differencing order (0 <= d <= max_d).

Determine the integration order d using repeated stationarity tests (Hyndman-Khandakar Step 1).
