Naive forecaster

peshbeen.models.naive

naive(
    target_col: 'str',
    season_period: 'Optional[int]' = None,
    box_cox: 'Union[bool, float]' = False,
    box_cox_biasadj: 'bool' = False
)

Naïve forecaster.

Two modes controlled by season_period:

  • Non-seasonal (season_period=None): every forecast step repeats the last observed value in the training series.
  • Seasonal (season_period=m): forecast values are taken from the last complete season and cycled forward — i.e. step h is predicted by y[T - m + ((h-1) % m)], where T is the last training index.
Type Default Details
target_col str Name of the target variable column.
season_period Optional[int] None Seasonal period m. None selects the non-seasonal naïve method. When provided and the training series is shorter than m, forecast returns an array of NaN.
box_cox Union[bool, float] False Whether to apply Box-Cox transformation to the target variable. If a float value is provided, it will be used as the lambda parameter for the Box-Cox transformation. If True, the lambda parameter will be estimated from the data.
box_cox_biasadj bool False Bias adjustment when inverting the manual Box-Cox on forecasts.
Returns None

Multivariate forecasters

Multivariate forecasters model joint dynamical systems where multiple target variables interact simultaneously. These models expect input data in wide format — a DataFrame where each column represents an endogenous target series (target_cols) sharing synchronous timestamps on a common DatetimeIndex.

  • ml_multi_output_forecaster: Employs scikit-learn regressors (or multi-output estimators) across wide target columns with automatic lag and transformation engineering.
  • var: Classical Vector Autoregression capturing linear dynamic cross-lag interactions.
  • ms_var: Markov-Switching Vector Autoregression capturing discrete regime shifts in joint series dynamics.

Multi-series forecasters

Multi-series forecasters train global models across collections of many individual time series (e.g., hundreds of SKUs or store items). These models expect input data in long (panel) format — a DataFrame containing an entity column (id_col), a target column (target_col), and timestamps.

  • panel_forecaster: Pools all series vertically without cross-series lag interaction (using standard lag_1, lag_2, ...). Highly scalable to large collections of series.
  • ml_multi_forecaster: Extends multi-series pooling by capturing cross-series lag interdependencies across series.

    y_pred: 'ArrayLike'
)

Calculate Cumulative Forecast Error (CFE). It is the cumulative sum of the differences between actual and predicted values.

Type Details
y_true ArrayLike The actual values.
y_pred ArrayLike The predicted values.
Returns float
